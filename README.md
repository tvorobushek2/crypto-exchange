### \\ Криптобиржа (Crypto Exchange)



#### \\ Описание системы



Данный проект представляет собой начальную версию клиент-серверного приложения криптобиржи. Система предназначена для управления пользователями (администраторы, менеджеры, клиенты-трейдеры) и обработки торговых заявок (ордеров) на покупку и продажу криптовалют.



#### \\ Структура проекта



Проект разработан на Java с использованием фреймворка Spring Boot и системы сборки Maven. Соблюден принцип единственной ответственности (SRP).



#### \\ Пакет model (корневой пакет com.example.cryptoexchange)



\- `UserRole` – перечисление ролей (ADMIN, MANAGER, CUSTOMER).

\- `User` – абстрактный базовый класс пользователя.

\- `AdminUser`, `ManagerUser`, `CustomerUser` – конкретные реализации пользователей.

\- `OrderType`, `OrderStatus` – перечисления для типов и статусов заявок.

\- `Order` – класс торговой заявки.



#### \\ Пакет service



\- `UserService` / `UserServiceImpl` – управление пользователями (добавление, поиск по роли, удаление, вывод).

\- `OrderService` / `OrderServiceImpl` – управление заявками, хранение в коллекциях (List, Map), поиск и фильтрация.

\- `OrderProcessingService` / `OrderProcessingServiceImpl` – многопоточная обработка заявок с именованными потоками.

\- `Main` – точка входа Spring Boot приложения.
